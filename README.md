# سُفريا — طلب مباشر للمطاعم عبر محادثة واتساب

> الزبون بيكتشف المطعم على تطبيقات التوصيل. **ومن طلبه التاني، بيطلب منه مباشرة بمحادثة واتساب**، والمطعم ما بيدفع عمولة على زبون كسبه أصلا.
> اشتراك شهري ثابت، بلا عمولة على الطلب. **واتساب قناة أولى، مش المنتج نفسه.**

**حالة هالملف:** 9 أكتوبر 2026. الحالة التفصيلية لكل متطلب موجودة بالـSRS (تحت).

---

## كيف بيشتغل

1. **الزبون** بيراسل رقم المطعم على واتساب، وبتوصله منيو مرقّمة.
2. **بيكتب أرقام الأصناف** (مثلا «2 و5»)، والسلة بتتكوّن جوا المحادثة. بعدها بيختار استلام أو توصيل، وبيأكّد.
3. **الطلب بيظهر على لوحة المطعم.** الموظف بيحرّكه بزر، والزبون بتوصله رسالة لما المطعم يقبل الطلب ولما يجهز.

ليش نص مرقّم مش أزرار واتساب؟ قوائم واتساب التفاعلية سقفها 10 صفوف و24 حرف للعنوان، وأي منيو حقيقي بيكسرها. والنص الحر بيسمح بـ«2 و5» بنفس الرسالة.

## الحالة — 9 أكتوبر 2026

### ✅ مبني ومختبر (على `main`)

- **محادثة الطلب كاملة:** منيو مرقّم · سلة بأوامر بسيطة (منيو · سلة · تم · شيل) · استلام أو توصيل مع العنوان ورسوم التوصيل · ملخّص وتأكيد · فحص توفّر الأصناف مرة تانية قبل ما ينكتب الطلب.
- **فهم كتابة الزبون:** الهمزات، والأرقام العربية (٥ = 5)، وكلمات اللهجة لإنهاء الطلب (مثلا «بس» و«هيك»).
- **ساعات الدوام:** المطعم المسكّر بيرد برسالة إغلاق فيها ساعاته، وما بتنفتح محادثة طلب.
- **مهلة الجلسة:** محادثة بتسكت 60 دقيقة بتبلّش من جديد بالترحيب والمنيو.
- **إشعارات الزبون:** لما المطعم يقبل الطلب، ولما يجهز (استلام أو «خرج للتوصيل»)، ولما ينلغى. «قيد التحضير» و«مكتمل» صامتين بقرار، عشان ما نزعج الزبون.
- **لوحة المطعم (عربي، من اليمين لليسار، من التلفون للابتوب):** الطلبات الحية والسجل · زر الخطوة الجاية · تفاصيل الطلب مع محادثة الزبون كاملة · الإلغاء مع سبب.
- **عملة لكل مطعم** (دينار أو شيكل)، ورقم طلب متسلسل لكل مطعم.
- **العزل بين المطاعم** بـPostgreSQL Row-Level Security، وبوابة أمان إلزامية بالـCI: **15 فحص + 4 ضوابط كسر**.
- **810 اختبار:** shared 185 · الواجهة 71 · المحرّك 215 · الـAPI 333 · قاعدة البيانات 6.

### 🔨 قيد البناء (بالترتيب)

1. **إدارة المنيو من اللوحة:** إضافة صنف، تعديل اسمه وسعره، إزالته، و«أوقف الطلبات مؤقتا». الجزء الخلفي قيد التنفيذ، والشاشة بعده.
2. **إعادة الطلب بضغطة (FR-08):** الزبون الراجع بيوصله آخر طلب إله، وبيعيده بكلمة وحدة.

### ⏸️ مؤجّل بقرار

الدفع الإلكتروني (اليوم كاش بس) · تحليلات المطعم (FR-17 لـFR-21) · تحصيل الاشتراك آليا · تخصيص رسائل البوت لكل مطعم · الاستضافة (اليوم تشغيل محلي، ورقم واتساب تجريبي).

## الستاك

| الجزء | التقنية |
|---|---|
| المستودع | TypeScript monorepo · pnpm 9.15.0 · Node 24 |
| `apps/conversation-engine` | محرّك المحادثة: webhooks واتساب، آلة الحالات، الإشعارات |
| `apps/dashboard-api` | NestJS 11: الـAPI تبع اللوحة |
| `apps/dashboard-web` | Next.js 16 / React 19: لوحة المطعم |

| الاختبارات | Jest للخدمتين · `node:test` لـshared والواجهة |

**الذكاء الاصطناعي بالتطوير:** الكود بيتكتب بمساعدة Claude Code. الفريق بيكتب المواصفات وبياخد القرارات وبيراجع، وكل تغيير بيمر بالاختبارات قبل ما يندمج.

## تشغيل محلي

```bash
cp .env.example .env     # عبّي مفاتيح قاعدة البيانات وواتساب
pnpm install
pnpm db:up               # PostgreSQL بـDocker
pnpm db:migrate          # بيطبّق الهجرات الجديدة بس
pnpm db:seed             # بيانات تطوير
pnpm test:security       # بوابة العزل بين المطاعم
```

المتوقع بآخر سطر من البوابة:

```
NOTICE:  ALL 15 ASSERTIONS PASSED — chain isolation gate is green
```

**الخدمات، كل وحدة بنافذة:**

```bash
pnpm --filter @sufria/dashboard-api dev          # الـAPI على 3002
pnpm --filter @sufria/conversation-engine dev    # المحرّك على 3001
pnpm --filter @sufria/dashboard-web dev          # اللوحة على 3000
```

- **مطعم تجريبي:** أمر التهيئة بـ`CLAUDE.md` (قسم Commands).
- **واتساب:** المحرّك بيستقبل على `/webhooks/whatsapp`. محليا بدك نفق (مثلا `cloudflared`)، ورابطه بيتحط بإعدادات تطبيق ميتا.
- **قبل أي push:** `pnpm verify` (تنسيق، lint، أنواع، بوابات التباين والأرقام وRTL، والاختبارات).

## قواعد ما بتنكسر

1. **بوابة الأمان خضرا، أو ما في دمج.** حمرا = مطعم ممكن يشوف بيانات مطعم تاني.
2. **الهجرات إضافة بس.** هجرة انطبقت ما بتتعدّل؛ التغيير بهجرة جديدة.
3. **الـSQL هو المصدر، والـTypeScript مرآة.** ممنوع `drizzle-kit generate`، لأنه بيمسح سياسات RLS بصمت.
4. **التطبيق ما بيتصل بالقاعدة كـsuperuser أبدا.** الـsuperuser بيتجاوز RLS بلا ولا رسالة خطأ.
5. **TypeScript مثبّت على `~5.9.3`.** الإصدار 7 بيكسر `nest build`.
6. **`.env` ما بيوصل git.** والاختبارات بتشتغل على قاعدة منفصلة، مش قاعدة المطعم التجريبي.

التفاصيل والأسباب بـ[`CLAUDE.md`](CLAUDE.md).
