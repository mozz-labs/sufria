## ⚡ تشغيل سريع

```bash
cp .env.example .env
pnpm install
pnpm db:up          # PostgreSQL بـDocker
pnpm db:migrate     # ١٣ جدول
pnpm db:seed        # بيانات اختبار
pnpm test:security  # 🔴 لحظة الحقيقة
```

**النتيجة المتوقعة:**
```
NOTICE:  ALL 12 ASSERTIONS PASSED — chain isolation gate is green
✓ البوابة الأمنية خضرا
```

شفت هالسطرين؟ بيئتك مضبوطة ١٠٠٪.

## 🔴 خمس قواعد ما بتنكسر

**٠. ممنوع الترقية إلى TypeScript 7.**
مثبّتة على `~5.9.3`. TS 7 بتكسر `nest build` — ما فيها compiler API برمجية. نفس الشي بيكسر ts-jest و ESLint النوعي. ADR-003.

**١. البوابة الأمنية خضرا، أو ما في دمج.**
`pnpm test:security` ١٢ فحص + ٣ ضوابط سالبة. حمرا = مطعم ممكن يشوف بيانات مطعم تاني. بلوبرينت §5.5.

**٢. الـmigrations append-only.**
انبنت عند حدا؟ ممنوع تعدّلها. اعمل `0004_...` جديدة. غير هيك قاعدة بياناتكم بتصير ٣ قواعد مختلفة.

**٣. الـSQL هو المصدر، مش الـTypeScript.**
`packages/shared/src/schema.ts` **مرآة يدوية**. ممنوع `drizzle-kit generate` — بيسقّط بصمت كل سياسة RLS وكل CHECK وكل فهرس جزئي. `pnpm test:db` بيمسك الانحراف.

**٤. `DATABASE_URL` لدور غير superuser.**
superuser بيتجاوز كل RLS **بلا رسالة خطأ**. `TenantDbService` بيرفض يقلع لو صار.

**٥. `.env` ما بيوصل جيت.**
لو صار: غيّر كل المفاتيح فورا. حذف الملف ما بيكفي — بيضل بالـhistory.

| Sprint | التواريخ | الهدف |
|---|---|---|

| **1** | ٢٣ أغسطس → ٣ سبتمبر | 🎯 طلب كاش كامل من أول رسالة للوحة |

### 🔴 ثلاثة تواريخ محفورة

| التاريخ | شو |
|---|---|
| **١ سبتمبر** | ميتا تنشر أسعار الرسائل الجديدة → **لا يُثبَّت سعر الاشتراك قبلها** |
| **٣ سبتمبر** | ٥ محادثات مع أصحاب مطاعم **مكتملة ومكتوبة** + قفل بلد الإطلاق (بداية تخطيط Sprint 2) |
| **١ أكتوبر** | كل رسالة صادرة بتصير مدفوعة — **البايلوت ما بيشتغل ولا يوم تحت المجاني** |

> **📌 تصحيح ١٥ أغسطس:** كان مكتوب هون "٣ سبتمبر = آخر يوم آمن لتقديم **تحقق واتساب**". **هذا كان غلط.** تحقق الأعمال (Business Verification) مطلوب للتوسّع، مش للتطوير ولا للبايلوت ولا للعرض. **رقم الاختبار مجاني وفوري وبلا أوراق**، والرقم الحقيقي غير المتحقق بيوصل **٢٥٠ زبون فريد / ٢٤ ساعة**. الحجة الكاملة بـ`docs/05-مهام-Sprint-0.md` (S0-B1).
