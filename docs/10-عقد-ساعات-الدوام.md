# عقد ساعات الدوام والمنطقة الزمنية

**آخر تعديل:** ١٢ سبتمبر ٢٠٢٦ · **الهجرة:** `0008_restaurants_timezone.sql`
· **التعريف بالكود:** `apps/conversation-engine/src/restaurant/business-hours.ts`

---

## ليش هالملف موجود

`restaurants.business_hours jsonb` انعلن بهجرة `0001` وضل فاضيا ما حدا بيكتب فيه
ولا بيقراه لحد ما انبنت بوابة الدوام (FR-22). وقتها انتعرّف الشكل **بالكود وبس** —
ما في مخطط بالقاعدة، ولا سطر توثيق، ولا CHECK.

يعني: شاشة الإعدادات لما تنبنى لازم تكتب شكلا **ما حدا كتبه بأي مكان**. هالملف
بيكتبه، وبيوثّق التغيير اللي صار بهجرة `0008`.

---

## 🔴 الشكل: شو كان وشو صار

### كان (من بوابة الدوام لحد هجرة 0008)

```jsonc
// restaurants.business_hours
{
  "timezone": "Asia/Amman",
  "days": {
    "sun": [{ "open": "09:00", "close": "23:00" }]
  }
}
```

المنطقة الزمنية كانت **جوّا الـjsonb**. السبب المسجّل وقتها بـ`CLAUDE.md`:

> «التوقيت يعيش داخل ذلك الـjsonb لأن `restaurants` مُمثَّل في `packages/shared`
> وعمود جديد هناك هو فشل انحراف مخطط.»

### صار (هجرة 0008)

```jsonc
// restaurants.timezone  — عمود text NOT NULL DEFAULT 'Asia/Amman'
"Asia/Amman"

// restaurants.business_hours
{
  "days": {
    "sun": [{ "open": "09:00", "close": "23:00" }]
  }
}
```

مفتاح `timezone` **انشال من كل الصفوف** بنفس الهجرة، وما عاد ينقرا.

### ليش انتغيّر

**السبب اللي كان مكتوب غلط.** عمود جديد بيصير فشل انحراف لما الـSQL يتغيّر
والمرآة لأ — **تغيير الاتنين سوا هو بالضبط شغل** `tests/db/schema-drift.verify.ts`.
وهجرة `0007` كانت قايلة هالشي بالحرف بترويستها:

> «that is a property of the drift check, not a reason to avoid columns»

يعني كشف الانحراف ما كان يوم عائقا، وكلفة الالتفاف عليه كانت حقيقية: حقل بلا نوع،
بلا تحقّق، وبلا توثيق، ولازم شاشة الإعدادات تخمّنه.

## العقد لشاشة الإعدادات

| الحقل | المكان | النوع | الافتراضي |
|---|---|---|---|
| المنطقة الزمنية | `restaurants.timezone` | `text` NOT NULL، اسم IANA | `Asia/Amman` |
| أيام ونوافذ الدوام | `restaurants.business_hours` | `jsonb` NOT NULL | `{}` |

### `business_hours`

```jsonc
{
  "days": {
    "sun": [{ "open": "09:00", "close": "23:00" }],
    "mon": [
      { "open": "10:00", "close": "14:00" },
      { "open": "18:00", "close": "23:00" }
    ]
  }
}
```

- **مفاتيح الأيام:** `sun mon tue wed thu fri sat` — والأسماء الطويلة
  (`sunday`…) مقبولة بالقراءة كمان. حروف صغيرة أو كبيرة ما بتفرق.
- **الوقت:** `"HH:MM"` ٢٤ ساعة، **أرقام غربية فقط** (`0-9`). `"9:00"` مقبولة،
  و`"09:00"` هي المعيار.
- **يوم مش موجود بالخريطة، أو موجود بمصفوفة فاضية** = مغلق كليا ذاك اليوم.
- **`business_hours` فاضي (`{}`)** = **مفتوح دايما**. هاد المسار الموثّق الوحيد
  للمطعم اللي بيشتغل ٢٤ ساعة.
- **نافذة صفرية (`open == close`)** بتنشال ولا بتنفهم كـ٢٤ ساعة. `"00:00"` لـ
  `"00:00"` = اليوم مغلق، مش مفتوح. غلطة إدخال ما بتفتح المطعم أبدا.
- **إغلاق بعد منتصف الليل** بينكتب طبيعي: `{"open":"22:00","close":"02:00"}`.
  القارئ بيفحص نافذة اليوم السابق كمان، فالساعة ١:٠٠ ص بتنحسب ضمن نافذة امبارح.
- **أي مفتاح زيادة بينتجاهل**، ويوم ما بينفحص بيسقط لحاله بدل ما يسقّط الحقل كله.

### 🔴 ممنوع تكتب `timezone` جوّا `business_hours`

انشال بهجرة `0008` وما عاد ينقرا. لو انكتب من جديد، المحرّك بيسجّل تحذير:

```
business_hours فيه مفتاح timezone مهجور — العمود restaurants.timezone هو المقروء
```

التحذير موجود عشان يكون العطل **ظاهرا** بدل ما تغيّر الشاشة المنطقة الزمنية
وما يصير إشي.

---

## 🔴 الاتجاه عند الشك: مفتوح، مش مغلق

حقل مشوّه (مش كائن أصلا)، أو منطقة زمنية Postgres وIntl ما بيعرفوها = **مفتوح**
\+ سطر خطأ بالسجل.

مطعم بيوقف عن استقبال الطلبات بسبب فاصلة ناقصة بالـjsonb بيخسر مبيعات **وهو ما
بيعرف** — الزبون بياخد «المطعم مغلق حاليا» والمطعم شغّال. بالمقابل مطعم استقبل
رسالة وهو مسكّر بيشوفها بعينه وبيتصرّف. الأول عطل صامت، والتاني إزعاج ظاهر.

## حدود معروفة

- **دوام مقسوم بيعرض أول نافذة بس** برسالة الإغلاق — نص الرسالة فيه خانتين مش
  أربعة. عرض «النافذة الجاية» بيصير وعدا محسوبا، وهاد بالضبط اللي هالنص بيتجنّبه.
- **`timezone` ما فيه CHECK بيتأكد إنه اسم IANA صالح.** التحقق بيحتاج قراءة
  `pg_timezone_names` وهي مش immutable، فممنوعة بـCHECK. الـCHECK الموجود بيرفض
  الفاضي وبس، والاسم المجهول بينمسك وقت القراءة (`Intl` بيرمي → مفتوح).
  شاشة الإعدادات لازم تعرض قائمة مناطق جاهزة، مش خانة نص حرة.
