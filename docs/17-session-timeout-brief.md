## 2. ح-1 · القرار — مقفول

- **الجلسة منتهية** إذا `now() - last_message_at >= 60 دقيقة`، وكانت حالتها مش `order_placed` ولا `abandoned`.
- **`last_message_at` = آخر رسالة من الزبون.** إذا الفحص 4 طلّع إنه بيتحدّث كمان عند رسائل البوت، **لا تغيّر هاد السلوك**، وسجّل بالتقرير شو معناه على المهلة.
- **الانتهاء «كسول» عند وصول الرسالة، بلا مهمة خلفية:** لما توصل رسالة والجلسة النشطة منتهية:
  1. `UPDATE … SET state = 'abandoned' WHERE id = $1 AND state = $الحالة_المقروءة` (CAS، نفس نمط الانتقالات القائم).
  2. صفر صفوف ← حدا سبقك. تابع بالمسار القائم بلا خطأ.
  3. بعدها **المسار القائم لجلسة جديدة حرفيا** (ترحيب + منيو، `browsing`). السلّة والعدّاد ونوع الطلب والعنوان كلهم بيبلّشوا فاضيين.
- **المدة من متغيّر بيئة** `SESSION_IDLE_MINUTES`، الافتراضي `60`، ويُضاف لـ`.env.example` بتعليق سطر واحد. (محمد بيحطه `1` مؤقتا ليجرّب على جهازه.)
- **سطر سجل** بمستوى `info` عند كل انتهاء: معرّف الجلسة القديمة · حالتها · قديش سكتت بالدقائق · رقم الزبون **مقنّع** (آخر 4).
- **ممنوع:** نص للزبون عن السلّة القديمة · تعديل العدّاد أو رسالة الاستسلام · مهمة دورية · أي تغيير بسلوك جلسة عمرها أقل من 60 دقيقة.

## 4. التجربة اليدوية

**بالـcloud:** بالمرسِل الوهمي، جلسة عالقة قديمة ← رسالة ← ترحيب ومنيو، والسجل فيه سطر الانتهاء.

**خطوات محمد على جهازه** (بالتقرير، أمر أمر بلغة بسيطة، وكل أمر يبدأ بـ`cd ~/sufria &&`):
1. سحب الفرع ← `pnpm install` ← `pnpm --filter ./packages/shared build`.
2. سطر `SESSION_IDLE_MINUTES=1` بـ`.env` **مؤقتا**.
3. تشغيل المحرّك والـAPI والنفق (كل وحدة بنافذة).
4. يبلّش طلب على واتساب ويوقف عند «استلام ولا توصيل؟».
5. يستنى دقيقة، ويبعت «مرحبا» ← **ترحيب ومنيو من جديد**.
6. يرجّع السطر لـ`60` أو يشيله.
